## 新手快速上手（第一次用先看這段）

照著做一遍就會了，一步一步來。

1. **先開好遊戲**：登入楓之谷 Worlds，把遊戲解析度設成 **1280×720**，而且只開一個遊戲視窗。
2. **解壓資料夾**：下載的 zip 按右鍵「解壓縮全部」，整個資料夾解出來，不要只拉出一個檔案。
3. **開程式**：在資料夾裡的 `pikapang.exe` 上按右鍵 →「以系統管理員身分執行」。
4. **輸入卡密**：跳出授權視窗時，把卡密貼上去，按確認（可勾「記住」，下次就不用再貼）。
5. **選遊戲視窗**：進主畫面後，照上面提示把目標遊戲視窗綁定好。
6. **開始掛機**：設定好要走的路線或動作後，按鍵盤 **F10** 開始；想暫停按 **F11**；想把視窗藏起來按 **F12**。

遇到看不懂的字或卡住，直接截圖找作者（Discord：`pikapang.`）。

## 攻擊怎麼設定（新手教學）

攻擊設定分在三個分頁，照順序填就好。

### 第一站：「基礎設定」頁 →「攻擊與移動」框

先決定你的角色是哪一種，**兩種擇一**：

**A. 近戰／一般職業（站著打）**
1. 勾「**主攻鍵**」。
2. 「按鍵」點一下，再按你遊戲裡的攻擊鍵（例如 `z`）。
3. 「間隔(毫秒)」填多久按一次，例如 `200`（＝每 0.2 秒按一下）。

**B. 法師（會瞬移的職業）**
1. 勾「**瞬移**」，「按鍵」填瞬移鍵，「距離」填離目標多遠才瞬移（不懂就先填 `30`）。
2. 「法師主攻」填攻擊鍵，「間隔(毫秒)」例如 `200`。
3. 想走到每個座標點時停下來原地多打幾下，就勾「**座標點補攻**」。

**走A（兩種都能開）**：勾了以後，走向座標的路上會一直按住攻擊鍵，邊走邊打。

同一頁下面還有幾個按鍵也要填：
- **彈跳鍵**：跳躍鍵。要爬繩往上一定要填。
- **撿物按鍵**：撿東西的鍵。
- **初始釋放技能**：按 F10 開始時先放一次的技能，例如 `1-300,2`（先按住 1 三百毫秒，再按 2）。

### 第二站：「座標模式」頁 →「攻擊路線」框

這裡決定角色要在地圖上怎麼走。
1. 站到你想打怪的位置，按 **F8**（或「新增座標」），這一點就會加到目前選中的那一行。
2. 換個位置再按 F8，重複幾次，一條路線就做好了。
3. 那一行最前面的「**啟用**」要**打勾**，路線才會跑（只是選中不算數）。
4. 其他選項：
   - **攻擊間隔**：每一步之間停多久（毫秒）。
   - **隨機執行**：有好幾條路線時，隨便挑一條跑。
   - **打亂座標**：同一條路線裡的點打亂順序走。
   - **隨機偏移**：每個點加一點點隨機，看起來比較像真人。
5. 按錯了：「刪除最後一點」刪掉剛加的點，「清空這行」整行重來。

### 第三站：「技能與輔助」頁（放技能、Buff、補給）

分成三個小分頁，用得到的才填，沒填的不會執行。

- **連續釋放**：每隔幾秒一口氣連放好幾招。
  寫法：`秒數,技能,技能,…`，例如 `30,1,2,3` ＝ 每 30 秒按 1、2、3。
  「連續釋放延遲」是每一招之間停多久（毫秒）。
- **間隔釋放**：要勾「啟用間隔釋放」。每一列填「鍵位」和「間隔(秒)」，例如鍵位 `4`、間隔 `60` ＝ 每 60 秒按一次 4。
- **定點定時技能**：最強的一張表，Buff、補給也寫在這裡。
  每一列填：**鍵位**、**間隔(秒)**、**方向**（`left`／`right`，可空白）、**座標**（要先走到哪裡再放，可空白）、**延遲(毫秒)**（放完停多久）。
  間隔可以寫範圍，例如 `20-25` ＝ 每 20～25 秒之間隨機挑一個時間放，比較不像機器。

### 按鍵寫法小抄（上面所有格子都通用）
| 寫法 | 意思 |
|---|---|
| `a,a,1` | 依序按 a、a、1 |
| `z-1000` | 按住 z 一秒再放開 |
| `down\|j` | 同時按 ↓ 和 j |
| `delay\|300` | 停 300 毫秒 |
| `(60,127)` | 走到小地圖上這個座標 |
| `rope\|(60,90)` | 爬繩到 y=90 |

方向鍵寫 `up`／`down`／`left`／`right`；其他鍵例如 `space`、`ctrl`、`alt`、`shift`、`F1`。

**都設好了 → 回遊戲 → 按 F10 開始。** 第一次建議先站在旁邊看一兩分鐘，確認打得到怪、路線沒走歪。

## 1. 這是什麼
- 產品名稱：楓星懶人包（內部代號 PIKAPANGSCRIPT）。
- 主程式：`pikapang.exe`（64 位元），背景 32 位元工作程序：`dmworker\dmworker.exe`。
- 用途：MapleStory Worlds 的輔助自動化（座標／錄製模式、爬繩、定時休息、測謊處理、自動回覆）。
- 只想要測謊與自動回覆、不需要掛機腳本的人，可改用獨立的「楓星測謊助手」。

## 2. 系統需求
- Windows 10／11 64 位元。
- 需要目標遊戲（MapleStory Worlds）單一視窗已開啟，畫面需為 **1280×720**。
- 不需另外安裝 Python／執行期，standalone 已自帶。

## 3. 安裝
1. 將 `楓星懶人包` 整個資料夾解壓到任意位置（路徑可含中文，免安裝）。
2. 務必保持資料夾結構完整，不要只單獨複製 `pikapang.exe`。
3. 在 `pikapang.exe` 上按右鍵 →「以系統管理員身分執行」。

## 4. 首次啟動
1. 出現「楓星懶人包 授權驗證」視窗 → 輸入卡密（可勾選記住）。
2. 驗證通過後進入主控臺；心跳失效會停止全部並關閉。
3. 首次執行後會自行產生：`profiles\_last.txt`、`profiles\_ui.json`、`logs\`，以及本機卡密／機器碼綁定快取（位於「文件\PIKAPANG_PRIVATE」）。這些屬正常生成物。
4. 有新版時啟動會提示，照提示到下載庫抓最新 zip 即可。

## 5. 熱鍵
| 鍵 | 功能 | 備註 |
|---|---|---|
| F8 | 新增座標（取座標） | 固定 |
| F9 | 錄製 | 固定 |
| F10 | 啟動／停止 | 可於設定自訂 |
| F11 | 暫停／繼續 | 可於設定自訂 |
| F12 | 隱藏／顯示 | 可於設定自訂 |

## 6. 基本流程
1. 先開好遊戲視窗（日誌若顯示「找到 0 個標題含 Maplestory 的視窗」代表尚未偵測到遊戲）。
2. 在主控臺選取／綁定目標視窗，依需求設定分頁參數（座標模式或錄製模式）。
3. 按 F10 啟動；F11 暫停；F12 隱藏視窗。
4. 測謊（驗證碼）與自動回覆模組會在背景依設定運作。

## 7. 座標模式功能
- **路線**：填一串座標點，角色依序走到各點。
- **爬繩**：地圖有繩子或梯子時，在路線裡寫 `rope|(繩子的x,要到的y)`，例如 `(40,150),rope|(60,90),(80,90)`。角色會先對準繩子，按住 ↑ 跳起來抓繩爬到那一層（往下爬按住 ↓，不會變成下跳）。抓不到會自動左右微調再試，爬繩沒有冷卻，比上跳技能穩。
  - 座標怎麼量：人站在繩子正下方看「人物當前座標」的 x，再爬到頂上平台看 y。
  - 往上爬需要在基礎設定填好彈跳鍵。
- **定時休息**：座標模式頁最下面可開「定時休息」。每隔幾分鐘自動走到你指定的安全區休息一陣子，再回路線繼續，時間可寫成範圍（例如每 40-60 分鐘休息 3-5 分鐘）。休息時補血補魔、測謊、自動回覆照常。

## 8. 自動回覆
- **同步模型**：模型欄是下拉選單，按「同步模型」會列出你的 API 可用的模型，直接選就好，也可以手動輸入。
- **對話測試**：按「對話測試」打一句玩家說的話，看 AI 會怎麼回。使用跟實戰完全相同的人設、角色名與回話修正，也會接續前面的對話；只顯示在測試視窗，不會送進遊戲。
- 觸發截圖只保留最近 50 張，長時間掛機不會越堆越多。

## 9. 疑難排解
- 「程式檔案完整性校驗未通過，疑似遭竄改」：
  代表核心二進位被改動（常見為防毒改寫或檔案損毀）。請刪除後重新解壓原版 zip，勿手動修改資料夾內檔案。
- 「找不到 python312.dll」或啟動即閃退：
  多半是只複製了單一 exe。請保留並使用完整資料夾（`dmworker\` 內需含 `python312.dll` 等相依）。
- 「插件未就緒」／無法綁定：以系統管理員執行；檢查防毒是否攔截。
- 找不到遊戲視窗：先確認遊戲已開且為單一視窗，畫面 1280×720。
- 卡密無效／到期：聯絡發行者更新授權（Discord：`pikapang.`）。
- 無法載入驅動程式，以下方法處理：
  1. 按 Win + I 開啟「設定」。
  2. 進入「隱私權與安全性」（或「更新與安全性」）→「Windows 安全性」。
  3. 點「裝置安全性」。
  4. 在「核心隔離」下方點「核心隔離詳細資料」。
  5. 把「記憶體完整性」切為「關閉」。
  6. 依提示重新啟動電腦。

## 10. 更新須知
- 防毒軟體或 SmartScreen 若跳出警告，請選「仍要執行」或將資料夾加入信任清單。
- 解壓後請保持資料夾完整，不要只單獨複製 `pikapang.exe`。
- 舊版的配置檔可以直接沿用。
