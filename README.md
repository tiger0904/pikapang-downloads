## 一、快速上手

**開始前三件事：**
1. 遊戲解析度調成 **1280×720**，只開**一個**遊戲視窗。
2. zip 整個資料夾解壓出來（別只拉 `pikapang.exe` 一個檔）。
3. `pikapang.exe` 按右鍵 →「**以系統管理員身分執行**」→ 貼卡密 → 進主畫面。

**全程記這 5 顆鍵：**
| 鍵 | 功能 |
|---|---|
| **F10** | 開始 / 停止 |
| **F11** | 暫停 / 繼續 |
| **F12** | 藏起來 / 顯示 |
| **F8** | 記下目前站的座標 |
| **F9** | 開始 / 結束錄製 |

**最短流程：** 綁遊戲 → 設小地圖 → 設攻擊鍵 → 標路線（記得打勾啟用）→ 按 F10。

## 二、選哪種掛法

**擇一使用：**

| | 座標模式 | 錄製模式 |
|---|---|---|
| 怎麼運作 | 你標幾個點，角色**看小地圖自動走過去**打怪 | 你親手打一遍，程式**照錄照重播** |
| 會不會自己修正 | 會（隨時看座標，被撞開會自己走回來） | 不會（盲放按鍵，被撞開就歪掉） |
| 適合 | 固定路線刷怪、要換層、怕被撞 | 動作複雜、想完全照自己的打法 |
| 要設小地圖嗎 | 要 | 不用 |

**不確定就用座標模式**，它比較聰明、也比較耐撞。

## 三、座標模式設定

### 第 1 步：首頁 — 綁遊戲、設小地圖
1. 在視窗清單選你的遊戲，綁定。
2. 設「**小地圖範圍**」（框住小地圖）和「**位置點顏色**」（點一下角色那個亮點）。
   ⚠️ 沒設這兩個，角色不會走。

### 第 2 步：基礎設定 — 攻擊與移動
看[第五章](#五攻擊怎麼設)把攻擊鍵、彈跳鍵設好。

### 第 3 步：座標模式 — 標攻擊路線
1. 站到想打的位置，按 **F8**，這點就加進目前選中那行。
2. 換位置再按 F8，重複幾次 → 路線完成。
3. ⚠️ **那行最前面「啟用」要打勾**，路線才會跑（只是選中不算）。
4. **來回刷**：直接標 A、B 兩點，角色回程會自動轉身，來回都打得到。
5. 其他鈕：攻擊間隔（步與步停多久）、隨機偏移（每次站位差一點、像真人）、刪除最後一點、清空這行。

### 第 4 步（可略）：技能與輔助
放 Buff、補給、定時技能，用得到才填：
- **連續釋放**：`30,1,2,3` ＝ 每 30 秒按 1、2、3。
- **間隔釋放**：勾啟用，每列填「鍵位 `4`、間隔 `60`」＝ 每 60 秒按一次 4。
- **定點定時技能**：每列填 鍵位、間隔(秒)、方向(left/right，可空)、座標(先走到再放，可空)、延遲。間隔可寫 `20-25`（隨機更像真人）。

**完成 → 回遊戲 → 按 F10。** 先在旁邊看 1～2 分鐘，確認打得到怪、沒走歪。

## 四、錄製模式設定

### 第 1 步：基礎設定
攻擊鍵、彈跳鍵、撿物鍵先填好（重播時會用到）。

### 第 2 步：錄一段
1. 「腳本名稱」打個名字（⚠️ **不能有空格和逗號**）。
2. 按 **開始錄製(F9)**。
3. ⚠️ **先用滑鼠點一下遊戲視窗**，再開始打怪（不點它收不到你的操作）。
4. 打完按 **F9** 結束，自動存檔。
> 跳躍鍵**別設成 alt**，會有怪問題。

### 第 3 步：執行方式
- **順序 / 隨機 / 打亂順序**（三選一）。
- **隨機偏移 ±__%**：每次重播時間差一點，像真人。
- **重放前先走到錄製時的起點**：勾了會先回到開錄位置再重播（路線型建議勾）。

### 第 4 步：腳本列表
每行：**啟用**（打勾才播）、**次數**（這輪播幾遍）、**腳本名稱**。
旁邊鈕：編輯（手改）、錄到這行（重錄覆蓋）、載入錄製檔（匯入別的 txt）。

**完成 → 回遊戲 → 按 F10。** 錄到的是 txt（按「開啟錄製資料夾」可看），能用記事本改。

## 五、攻擊怎麼設

到「基礎設定 → 攻擊與移動」，**先決定你的角色怎麼打**。

### A. 近戰（站著打）
1. 勾「**主攻鍵**」→ 填攻擊鍵（如 `z`）。
2. 「間隔(毫秒)」填 `200`（每 0.2 秒打一下）。

### B. 法師（會瞬移）
1. 勾「**瞬移**」→ 填瞬移鍵 →「距離」填 `30`。
2. 「法師主攻」填攻擊鍵、間隔 `200`。
3. 想走到每點停下多打幾下，勾「**座標點補攻**」。

### 走A（可選）：邊走邊打
勾了之後，走向座標的路上會**一直按住攻擊鍵**，邊走邊打，效率高。

> ⚠️ **走A只適合「可以邊移動邊攻擊」的技能。**
> 如果你的攻擊是**原地硬直**（施放中不能走、或攻擊會打斷移動），開走A會**卡死**。
> 這種角色請**關掉走A**，改用下面的「定點攻擊」。

### 定點攻擊（原地硬直技能用這個）
路線用**座標和按鍵交錯**寫，走到點會先停下再按：
```
(40,150),z,(80,150),z,(120,150),z
```
＝ 走到 40 停下按 z、走到 80 停下按 z…。要連招就寫滿：`(40,150),z,x,c,(80,150),z,x,c`。
這種角色：**近戰不要勾走A**、**法師不要勾座標點補攻**。

### 其他要填的鍵
- **彈跳鍵**：跳躍鍵（換層一定要填）。
- **撿物按鍵**：撿東西的鍵。
- **初始釋放技能**：按 F10 時先放一次，例 `1-300,2`。

## 六、換層

程式會自己判斷：目標在上面就往上、在下面就下跳，到同一層再水平走過去。你只要把**落腳點設成座標點**、並填好對應的鍵。

### 往上：小臺階用「彈跳鍵」
高度差小的平台，填好「彈跳鍵」就會跳上去。

### 往上：有繩子用爬繩（最穩）
路線寫 `rope|(繩子的x,要到的y)`：
```
(40,150),rope|(60,90),(80,90)
```
角色對準繩子、按住 ↑ 爬上去（往下按 ↓）。沒冷卻、不吃技能，比跳穩。
> 量法：站繩子正下方看座標 x，爬到上層看 y。

### 往下：下跳
「下跳自定義」填好（通常 `down|彈跳鍵`），目標在下面就會下跳。

### 階梯平台（A→B→C 一層層往上、沒繩子）
⚠️ **別只設頂層一個點**指望它自己爬三層——程式要「水平接近目標才跳」，只設頂點會在中途平台走到底撞牆卡住。

**正解：每一階的落腳點都設一個座標點：**
```
(40,150),(70,120),(100,90),(160,90)
```
＝ A 平台(40) → 跳上 B(70,120) → 跳上 C(100,90) → 到頂層同 Y 後走到 160。
每段只差「一小段水平＋一階高度」，程式就一階一階跳上去。

## 七、特殊角色：沒有位移技能

**沒有上跳技能、沒有瞬移，照樣能掛**，只要這樣設：

1. **水平移動、來回、攻擊**：完全正常，靠走路就行（瞬移只是法師加速，不是必需）。
2. **攻擊技能不能邊走**：關掉走A，用[定點攻擊](#五攻擊怎麼設)（座標+按鍵交錯）。
3. **往上換層**：
   - 小臺階 → 填「**彈跳鍵**」即可。
   - 階梯平台 → 每階設一個座標點（見[第六章](#六換層)）。
   - 一跳上不去、需要二段跳 → 二段跳不吃技能，就是彈跳鍵按兩下：
     - 到基礎設定勾「**上跳**」，自訂填 `空格,空格`（彈跳鍵按兩次；換成你的跳鍵）。
     - 「**上跳距離**」設小一點（如 3），平台一高過它就改用二段跳。
4. **極限提醒**：某階連二段跳都上不去 = 這張地圖對無位移角色本來就上不去，程式會跳過該點。這種點別放進路線，改走有繩/有小臺階的路。

## 八、被怪撞到會怎樣

**座標模式天生耐撞**，因為它隨時在看小地圖座標：
- 被撞**遠離**目標 → 下一瞬間發現離遠了，繼續走回來。
- 被撞**過頭、方向反了** → 自動轉身走回來。
- 被撞到**原地僵持**（怪一直頂著）→ 連續一段時間沒更靠近，就判定卡住、跳過這點換下一點，不會卡死。

**唯一會偶發失誤的情況**：剛好「到點的瞬間」被撞開，而這點又要**原地做事**（定點放技能、座標點補攻、撿物）——那次可能放在錯位置、打空一次。影響很小，下一輪繞回來通常會補；只有「必須站定點的關鍵 Buff」比較明顯。真的在意可找作者開「定點前先確認站位」的加強。

**錄製模式不耐撞**：它盲放按鍵、不看座標，被撞開後整段會歪掉、回不來。怕撞就用座標模式。

## 九、其他功能

### 定時休息（座標模式頁最下面）
每隔一段時間自動走到安全點休息再回來。時間可寫範圍，例「每 40-60 分鐘休息 3-5 分鐘」。休息時補血補魔、測謊、自動回覆照常。

### 死亡回圖（死亡回圖頁）
偵測到角色死掉時怎麼處理，四選一：**死亡停止 / 等待後回圖 / 傳送石 / 無操作**。
- **怎麼判斷死了**：擷取一張「死亡畫面圖片」當模板，或設「血量 0% 持續幾秒」。
- **復活**：可設復活點選位置、確認鍵、回城鍵、復活後等待秒數。
- **回圖動作**：用「鍵鼠操作」（點 NPC、對話方塊）和「座標操作」（走回打怪點）把回去的路排好，支援傳送門。

### 測謊（驗證碼自動處理）
背景自動偵測測謊彈窗並辨識作答，不用你顧，預設開著。

### 自動回覆（AI 聊天）
- **同步模型**：填好 API 位址和金鑰，按「同步模型」列出可用模型，直接下拉選。
- **對話測試**：打一句話測 AI 怎麼回，只顯示在測試視窗、不會送進遊戲。

## 十、按鍵寫法小抄

所有填按鍵的格子都通用：

| 寫法 | 意思 |
|---|---|
| `a,a,1` | 依序按 a、a、1 |
| `z-1000` | 按住 z 一秒再放 |
| `down\|j` | 同時按 ↓ 和 j |
| `delay\|300` | 停 300 毫秒 |
| `(60,127)` | 走到小地圖這個座標 |
| `rope\|(60,90)` | 爬繩到 y=90 |

方向鍵寫 `up` / `down` / `left` / `right`；其他如 `space`、`ctrl`、`alt`、`shift`、`F1`。

**位移技能（先轉身再往前衝那種）**：
```
(40,150),left-150,a,(120,150),right-150,a
```
`left-150` = 按住左 150 毫秒確實轉身，再放 a 往左衝；技能還在播就加 `delay|400`。

## 十一、卡住了看這裡

| 症狀 | 多半是 |
|---|---|
| 角色完全不走 | 小地圖範圍/位置點顏色沒設；或那行路線「啟用」沒打勾 |
| 開走A就卡死不動 | 攻擊技能不能邊走 → 關走A、改定點攻擊（見第五章） |
| 階梯地圖爬不上去 | 只設了頂層一個點 → 每階各設一個座標點（見第六章） |
| 某層怎樣都上不去 | 沒位移技能又太高 → 二段跳設上跳自定義，或該點本就上不去 |
| 找不到遊戲視窗 | 遊戲沒開、開多個、或不是 1280×720 |
| 插件未就緒 / 綁不上 | 沒用系統管理員執行，或被防毒攔 |
| 錄製收不到操作 | 開錄後忘了先用滑鼠點一下遊戲視窗 |
| 無法載入驅動 | 設定 → 隱私權與安全性 → Windows 安全性 → 裝置安全性 → 核心隔離 → 關閉「記憶體完整性」→ 重開機 |

## 安裝與系統需求

- **系統**：Windows 10／11 64 位元。
- **遊戲**：MapleStory Worlds 單一視窗、畫面 **1280×720**。不需另外裝 Python／執行期，程式已自帶。
- **安裝**：
  1. 把 `楓星懶人包` 整個資料夾解壓到任意位置（路徑可含中文，免安裝）。
  2. 務必保持資料夾結構完整，不要只單獨複製 `pikapang.exe`。
  3. `pikapang.exe` 按右鍵 →「以系統管理員身分執行」。
- **首次啟動**：出現授權視窗 → 貼卡密（可勾記住）→ 進主控臺。首次會自動生成 `profiles\`、`logs\` 與本機卡密／機器碼綁定快取（文件\PIKAPANG_PRIVATE），屬正常。
- **更新**：有新版啟動會提示，到下載庫抓最新 zip 解壓即可，舊版配置檔可直接沿用。防毒或 SmartScreen 跳警告請選「仍要執行」或把資料夾加入信任清單。

> 只想要測謊與自動回覆、不要掛機腳本的人，可改用獨立的「楓星測謊助手」。
