# 楓星懶人包 使用教學

**作者：皮卡胖｜Discord：`pikapang.`**（安裝、卡密、問題都找這裡）

> 照著順序做，第一次大約 10 分鐘就能開始掛機。

---

## 一、開始前一定要做的三件事

1. **整個資料夾解壓縮**，不要只複製 `pikapang.exe` 出來。資料夾放在 `C:\楓星懶人包` 這種簡單的位置最好，路徑不要太深。
2. **右鍵 `pikapang.exe` →「以系統管理員身分執行」**，跳出授權視窗時**貼上卡密**（可以勾「記住」），就會進到主畫面。沒有用系統管理員身分開，按鍵會送不進遊戲。
3. **遊戲畫面要是 1280×720**。綁定好遊戲視窗後（第三章第 1 步），在首頁按「**一鍵設定視窗**」就會自動調好（寬、高預設就是 1280、720）。

如果打開時被 Windows 擋住、`pikapang.exe` 不見、或一直跳警告，先看下面的〈二、讓 Windows 不要擋程式〉。

---

## 二、讓 Windows 不要擋程式

### 為什麼會被擋？

懶人包要在背景幫你按鍵、看遊戲畫面，這種程式很容易被防毒軟體**誤判**成可疑程式，擋下來或直接刪掉。

> 建議先做 **方法 1**（只放行這個資料夾），大部分人做完就能用。
> 還是被擋，再往下做方法 2～5。

### 方法 1：把懶人包資料夾加進「排除項目」（最推薦）

只對這個資料夾放行，電腦其他地方照樣有防護。

1. 按鍵盤 `Win` 鍵，輸入 **Windows 安全性**，打開它。
2. 點 **病毒與威脅防護**。
3. 往下找到「病毒與威脅防護設定」，點 **管理設定**。
4. 拉到最下面，點 **新增或移除排除項目**。
5. 跳出「是否允許此 App 變更」時按 **是**。
6. 點 **＋ 新增排除項目 → 資料夾**，選整個懶人包資料夾（例如 `C:\楓星懶人包`）。

> **更快的做法**：在開始按鈕上按右鍵 →「終端機（系統管理員）」或「Windows PowerShell（系統管理員）」，貼上下面這行，把路徑換成你的資料夾，按 Enter：
>
> ```powershell
> Add-MpPreference -ExclusionPath "C:\楓星懶人包"
> ```

### 方法 2：暫時關閉「即時保護」

解壓縮、第一次開程式時，最容易被即時保護擋下來。

1. **Windows 安全性 → 病毒與威脅防護 → 管理設定**。
2. 把 **即時保護** 切到「關閉」，跳出提示按 **是**。
3. 這時候再解壓縮、打開程式，然後回去做**方法 1**。

> 即時保護關掉一段時間後，Windows 會自己再打開，這是正常的。只要做過方法 1，之後打開也不會再擋懶人包。

### 方法 3：檔案被刪掉了？從「保護歷程記錄」救回來

`pikapang.exe` 或資料夾裡的檔案不見時：

1. **Windows 安全性 → 病毒與威脅防護 → 保護歷程記錄**。
2. 找到跟懶人包有關的那筆（路徑是懶人包資料夾的），點開。
3. 按 **動作 → 還原**（或「允許在裝置上」）。
4. 還原之後記得做**方法 1**，不然下次還是會被刪。

> 如果救不回來，就把下載的壓縮檔**重新解壓縮一次**（先做方法 1 或方法 2 再解壓縮）。

### 方法 4：關閉「核心隔離」裡的「記憶體完整性」

**只有在下面這些情況才需要做**：日誌一直顯示「插件註冊失敗」、「繫結失敗」，或做完方法 1、2 還是不能用。

1. **Windows 安全性 → 裝置安全性**。
2. 點「核心隔離」下面的 **核心隔離詳細資料**。
3. 把 **記憶體完整性** 切到「關閉」。
4. 同一頁如果有 **Microsoft 易受攻擊的驅動程式封鎖清單**，也一起關閉。
5. **重新開機**，設定才會生效。

> 日誌如果只出現「附加保護（h3）在這台電腦未啟用」，那是正常提示，**不影響使用**，不用為了它關核心隔離。

### 方法 5：跳出「Windows 已保護您的電腦」（藍色視窗）

這是 SmartScreen 的提示，不是病毒警告。

1. 點視窗裡的 **其他資訊**。
2. 按下面出現的 **仍要執行**。

如果一直被擋，可以關掉這個提示：
**Windows 安全性 → 應用程式與瀏覽器控制 → 以信譽為基礎的保護設定**，把 **檢查應用程式和檔案** 切到「關閉」。

> **Windows 11 使用者**：如果同一頁有 **智慧型應用程式控制**，而且是「開啟」狀態，它會直接擋掉程式。
> 注意：智慧型應用程式控制**一旦關閉，就沒辦法再打開**（除非重灌系統），關之前請先想清楚。

### 有裝其他防毒軟體？

360、火絨、卡巴斯基、Avast、Norton 這類防毒軟體，各自都有防護。請在那套軟體裡把懶人包資料夾加進 **信任區／白名單／排除清單**，做法跟方法 1 一樣，只是位置在那套軟體自己的設定裡。

### 安全小提醒

- 懶人包只從**官方下載頁**下載，不要用別人轉傳的檔案。
- 方法 1（只排除這個資料夾）是最安全的做法。整個關掉即時保護或核心隔離，會讓電腦其他地方也少一層防護，不掛機的時候可以開回來。

## 三、最快上手（第一次設定）

### 第 1 步：綁定遊戲視窗（首頁）

1. 先開遊戲，進到角色畫面。
2. 在懶人包首頁按 **重新整理遊戲**，在列表裡**雙擊**你的遊戲視窗。
   （也可以把「⊕ 拖曳綁定」直接拖到遊戲視窗上。）
3. 看到「已繫結」就完成了。

### 第 2 步：讓程式看得懂畫面（畫面識別）

1. 按 **自動找小地圖**，小地圖的位置會自動填好。
2. 按「位置點顏色」旁邊的 **取色**，在小地圖上點一下**自己角色的黃點**。
3. 血條、魔條按旁邊的 **框選**，框住遊戲下方的紅條、藍條。
4. 按 **測試識別**：能讀到「人物座標」和血量、魔量的百分比，就代表設定好了。

### 第 3 步：設定補血、補魔（補給與攻擊）

- 勾選 **補血 HP**，填藥水按鍵，以及「血量低於幾 % 就喝」。補魔 MP 也一樣。

### 第 4 步：一鍵學圖（最推薦，照頁面上的 ①②③ 做）

站在想練的地圖上，打開 **一鍵學圖** 頁：

| 步驟 | 要按什麼 | 會發生什麼 |
|---|---|---|
| ② 試技能鍵 | 在「技能鍵」欄填你的技能鍵，例如 `z,x,shift`，再按 **試技能鍵** | 程式在原地把每個鍵試一次，判斷哪個是主攻、瞬移、上跳、Buff，確認後才幫你填好 |
| ① 框選繩子 | （**不能上跳的職業才需要**）按 **框選繩子…**，在小地圖上把每條繩子從頂框到底 | 學圖時只會爬你框的繩子 |
| ③ 打怪設定 | 照「下一步」那一行的提示按：**擷取名牌**、**擷取怪物**、**框選攻擊範圍** | 程式就能認出你、認出怪、知道打得到多遠 |
| ① 開始學圖 | 按 **開始學圖** | 角色自己把整張圖走一遍，量出每一層和換層的路，排好路線，確認後幫你填好 |

「打怪設定」那一行全部打勾，就完成了。

### 第 5 步：開始掛機

按 **F10** 開始，再按一次 F10 停止。

開著「**掛機時邊打邊自學習**」（預設就是開的），程式會越掛越聰明：

- 沒有怪的層，只經過、不去巡。
- 怪重生要幾秒，就等幾秒，不會空等。
- 常常跳不上去的地方，會改走別的路。

## 四、職業小提醒（看你的職業要不要開）

每個職業的技能都不一樣，下面這些**預設都是關的**，符合你的職業再開。它們都在 **移動設定** 頁。

| 你的職業如果… | 要做的設定 |
|---|---|
| **不能上跳**，只能爬繩、二段跳 | 一鍵學圖頁先 **框選繩子**；「補給與攻擊」頁要填 **彈跳鍵** |
| 有**往背後移動**的位移技能（要面向反方向放） | 勾 **反向位移**，填技能鍵（試技能鍵通常會自動幫你填） |
| 主攻是兩招連段，**第一招要前方有怪才會衝過去** | 主攻鍵框**雙擊**後打字，寫成 `a,b`，再勾 **主攻第一段要確認位移才接下一段** |
| 要用**二段跳去追怪** | 勾 **二段跳只用來接近怪物／找怪**（要開主動索敵） |

## 五、所有頁面在做什麼

| 頁面 | 一句話說明 |
|---|---|
| 首頁 | 綁定遊戲視窗 |
| 開始前檢查 | 幫你檢查還有哪些沒設定，點「前往設定」直接跳過去 |
| 畫面識別 | 小地圖、黃點、血條、魔條 |
| 補給與攻擊 | 補血補魔、主攻鍵、瞬移、走A |
| 移動設定 | 上跳、下跳、彈跳，以及上面那幾個職業開關 |
| 技能設定 | Buff、定時放的技能 |
| **一鍵學圖** | **自動學地圖、試技能鍵、打怪設定（新手從這裡開始）** |
| 座標路線 | 自己手寫走位路線（學圖會自動幫你填） |
| 主動索敵 | 看到怪才停下來打的細部設定 |
| 撿錢與休息 | 定時撿錢、定時走去安全的地方休息 |
| 錄製模式 | 錄下你自己的操作，照著重放（按 F9 開始錄） |
| 死亡與回圖 | 死掉之後自動復活、走回原本的地圖 |
| 測謊 | 跳出測謊時自動作答 |
| 自動回覆 | 有人跟你說話時自動回一句（要先按「**框選輸入框…**」框住聊天輸入列） |
| 來人提醒 | 有其他玩家靠近時響鈴提醒 |
| 日誌 | 程式在做什麼，都寫在這裡 |
| 配置與快捷鍵 | 存檔、讀檔、改熱鍵 |
| 授權與關於 | 卡密、版本 |

## 七、常見問題

**Q：按了 F10，角色完全不動？**
A：請確認是用「**以系統管理員身分執行**」開的。再看首頁有沒有顯示「已繫結」。

**Q：日誌一直說「小地圖上找不到人物黃點」？**
A：到「畫面識別」頁，重新按 **取色**，點自己角色的黃點；再按 **測試識別** 確認。

**Q：血很低了卻不喝水？**
A：遊戲改版後血條位置可能變了。到「畫面識別」頁，把血條、魔條重新 **框選** 一次。

**Q：自動回覆送不出去？**
A：到「自動回覆」頁按 **框選輸入框…**，框住遊戲左下聊天視窗最底下那條白色輸入列，再按 **測試發話…** 試一次。

**Q：停止之後，好像有鍵一直卡住？**
A：按一下鍵盤上的 `Win` 鍵就會解除。

**Q：程式被防毒刪掉、打不開？**
A：看〈二、讓 Windows 不要擋程式〉的方法 1 和方法 3。

**Q：學圖排出來的路線走起來怪怪的？**
A：一鍵學圖頁重新按一次 **開始學圖**。學之前先確認繩子都框好了，角色站在比較平的地方再開始。

**Q：更新新版本後，設定要重設嗎？**
A：不用。第一次開新版時，會自動帶入上一版的配置、模板、錄製檔，還有自學習學到的資料。

**Q：可以縮小遊戲視窗嗎？**
A：不行。遊戲視窗可以被其他視窗蓋住，但**不能最小化**（最小化就看不到畫面了）。

## 八、其他

- **系統需求**：Windows 10／11 64 位元。不用另外安裝 Python 或其他程式，程式已經自帶。
- **更新**：有新版時程式會提示，到下載頁抓最新的 zip 解壓縮就好，設定會自動帶過去。
