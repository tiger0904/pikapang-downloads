# 楓星懶人包 使用教學

**作者：皮卡胖｜Discord：`pikapang.`**（安裝、卡密、問題都找這裡）

> 照著順序做，第一次大約 10 分鐘就能開始掛機。
>
> 會用之後想把打怪調得更快、更穩，看 **[《參數調整與技能搭配指南》](參數調整與技能搭配指南.md)**：五種打法、每頁參數的建議值、技能怎麼排列組合、各種情境的配方。

## 一、開始前一定要做的三件事

1. **整個資料夾解壓縮**，不要只複製 `pikapang.exe` 出來。資料夾放在 `C:\楓星懶人包` 這種簡單的位置最好，路徑不要太深。
2. **右鍵 `pikapang.exe` →「以系統管理員身分執行」**，跳出授權視窗時**貼上卡密**（可以勾「記住」），就會進到主畫面。沒有用系統管理員身分開，按鍵會送不進遊戲。
3. **遊戲畫面要是 1280×720**。綁定好遊戲視窗後（第三章第 1 步），在首頁按「**一鍵設定視窗**」就會自動調好（寬、高預設就是 1280、720）。

如果打開時被 Windows 擋住、`pikapang.exe` 不見、或一直跳警告，先看下面的〈二、讓 Windows 不要擋程式〉。

## 二、讓 Windows 不要擋程式

### 為什麼會被擋？

懶人包要在背景幫你按鍵、看遊戲畫面，這種程式很容易被防毒軟體**誤判**成可疑程式，擋下來或直接刪掉。

> 建議先做 **方法 1**（只放行這個資料夾），大部分人做完就能用。
> 還是被擋，再往下做方法 2～5。

### 方法 1：把懶人包資料夾加進「排除項目」（最推薦）

只對這個資料夾放行，電腦其他地方照樣有防護。

1. 按鍵盤 `Win` 鍵，輸入 **Windows 安全性**，打開它。
2. 點 **病毒與威脅防護**。
3. 往下找到「病毒與威脅防護設定」，點 **管理設定**。
4. 拉到最下面，點 **新增或移除排除項目**。
5. 跳出「是否允許此 App 變更」時按 **是**。
6. 點 **＋ 新增排除項目 → 資料夾**，選整個懶人包資料夾（例如 `C:\楓星懶人包`）。

> **更快的做法**：在開始按鈕上按右鍵 →「終端機（系統管理員）」或「Windows PowerShell（系統管理員）」，貼上下面這行，把路徑換成你的資料夾，按 Enter：
>
> ```powershell
> Add-MpPreference -ExclusionPath "C:\楓星懶人包"
> ```

### 方法 2：暫時關閉「即時保護」

解壓縮、第一次開程式時，最容易被即時保護擋下來。

1. **Windows 安全性 → 病毒與威脅防護 → 管理設定**。
2. 把 **即時保護** 切到「關閉」，跳出提示按 **是**。
3. 這時候再解壓縮、打開程式，然後回去做**方法 1**。

> 即時保護關掉一段時間後，Windows 會自己再打開，這是正常的。只要做過方法 1，之後打開也不會再擋懶人包。

### 方法 3：檔案被刪掉了？從「保護歷程記錄」救回來

`pikapang.exe` 或資料夾裡的檔案不見時：

1. **Windows 安全性 → 病毒與威脅防護 → 保護歷程記錄**。
2. 找到跟懶人包有關的那筆（路徑是懶人包資料夾的），點開。
3. 按 **動作 → 還原**（或「允許在裝置上」）。
4. 還原之後記得做**方法 1**，不然下次還是會被刪。

> 如果救不回來，就把下載的壓縮檔**重新解壓縮一次**（先做方法 1 或方法 2 再解壓縮）。

### 方法 4：關閉「核心隔離」裡的「記憶體完整性」

**只有在下面這些情況才需要做**：日誌一直顯示「插件註冊失敗」、「繫結失敗」，或做完方法 1、2 還是不能用。

1. **Windows 安全性 → 裝置安全性**。
2. 點「核心隔離」下面的 **核心隔離詳細資料**。
3. 把 **記憶體完整性** 切到「關閉」。
4. 同一頁如果有 **Microsoft 易受攻擊的驅動程式封鎖清單**，也一起關閉。
5. **重新開機**，設定才會生效。

> 日誌如果只出現「附加保護（h3）在這台電腦未啟用」，那是正常提示，**不影響使用**，不用為了它關核心隔離。

### 方法 5：跳出「Windows 已保護您的電腦」（藍色視窗）

這是 SmartScreen 的提示，不是病毒警告。

1. 點視窗裡的 **其他資訊**。
2. 按下面出現的 **仍要執行**。

如果一直被擋，可以關掉這個提示：
**Windows 安全性 → 應用程式與瀏覽器控制 → 以信譽為基礎的保護設定**，把 **檢查應用程式和檔案** 切到「關閉」。

> **Windows 11 使用者**：如果同一頁有 **智慧型應用程式控制**，而且是「開啟」狀態，它會直接擋掉程式。
> 注意：智慧型應用程式控制**一旦關閉，就沒辦法再打開**（除非重灌系統），關之前請先想清楚。

### 有裝其他防毒軟體？

360、火絨、卡巴斯基、Avast、Norton 這類防毒軟體，各自都有防護。請在那套軟體裡把懶人包資料夾加進 **信任區／白名單／排除清單**，做法跟方法 1 一樣，只是位置在那套軟體自己的設定裡。

### 安全小提醒

- 懶人包只從**官方下載頁**下載，不要用別人轉傳的檔案。
- 方法 1（只排除這個資料夾）是最安全的做法。整個關掉即時保護或核心隔離，會讓電腦其他地方也少一層防護，不掛機的時候可以開回來。

## 三、最快上手（第一次設定）

### 第 1 步：綁定遊戲視窗（首頁）

1. 先開遊戲，進到角色畫面。
2. 在懶人包首頁按 **重新整理遊戲**，在列表裡**雙擊**你的遊戲視窗。
   （也可以把「⊕ 拖曳綁定」直接拖到遊戲視窗上。）
3. 看到「已繫結」就完成了。

### 第 2 步：讓程式看得懂畫面（畫面識別）

1. 按 **自動找小地圖**，小地圖的位置會自動填好。
   （掛機中不會自動改小地圖範圍。換了地圖、小地圖大小不一樣時，再按一次 **自動找小地圖**，或按旁邊的 **框選** 自己框。）
2. 按「位置點顏色」旁邊的 **取色**，在小地圖上點一下**自己角色的黃點**。
3. 血條、魔條按旁邊的 **框選**，框住遊戲下方的紅條、藍條。
4. 按 **測試識別**：能讀到「人物座標」和血量、魔量的百分比，就代表設定好了。

### 第 3 步：設定補血、補魔（補給）

- 勾選 **補血 HP**，填藥水按鍵，以及「血量低於幾 % 就喝」。補魔 MP 也一樣。

### 第 4 步：一鍵學圖（最推薦，照頁面上的 ①②③ 做）

站在想練的地圖上，打開 **一鍵學圖** 頁：

| 步驟 | 要按什麼 | 會發生什麼 |
|---|---|---|
| ② 試技能鍵 | 在「技能鍵」欄填你的技能鍵，例如 `z,x,shift`，再按 **試技能鍵** | 程式在原地把每個鍵試一次，判斷哪個是主攻、瞬移、上跳、Buff，確認後才幫你填好 |
| ① 框選繩子 | （**不能上跳的職業才需要**）走到繩子旁邊按 **框選繩子…**，在遊戲畫面上把繩子從頂框到底（每條繩子各框一次） | 學圖時只會爬你框的繩子 |
| ③ 打怪設定 | 照「下一步」那一行的提示按：**擷取名牌**、**擷取怪物**、**框選攻擊範圍** | 程式就能認出你、認出怪、知道打得到多遠 |
| ① 開始學圖 | 按 **開始學圖** | 角色自己把整張圖走一遍，量出每一層和換層的路，排好路線，確認後幫你填好 |

「打怪設定」那一行全部打勾，就完成了。

> **不想跑學圖、只想靠繩子上下換層？** 到 **座標路線** 頁按 **框繩子加入路線**，在遊戲畫面上把一條繩子從頂框到底，程式會自動換算、把爬繩那一步加進你選中的那行路線，不用先學圖。站在繩子下端框就往上爬、站在上端框就往下爬，程式自己判斷（日誌會寫出結果）。一條繩子框一次，站在要出發的那一端、繩子旁邊框最準。

> **同一張地圖有傳送門（站 A 點按 ↑ 傳到 B 點）？** 到 **座標路線** 頁按 **框傳送門加入路線**：先站在入口**正中間**按一下（記下入口座標），再自己走到出口那一端站好、按第二下（記下出口座標），程式就把「走到入口→按 ↑ 傳到出口」這一步加進你選中的那行路線。跑圖時會先挪到你記的那一格、在附近連按 ↑，確定傳過去就停手（不會站在出口又被傳回去）；被怪撞開會自己走回去再按，落點跟你記的出口差幾格也算到。要讓一鍵學圖也認得這道傳送門，改在「一鍵學圖」頁按 **記傳送門…**，一樣記兩下，探索時就會把它加成換層點。

> **熟的圖想自己畫路線？** 到 **座標路線** 頁切到 **小地圖畫路線** 分頁，先按 **截小地圖**，在小地圖上點一下放一個點（點人要站的地面），或按住拖曳畫一整段；上方「畫」選 **爬繩／二段跳／傳送門** 再點，就是換層點。拖點可以微調位置、右鍵刪掉。繩子先在小地圖上粗點一下，再按 **框畫面繩子精修** 到遊戲畫面上把那條繩子框準。畫好按 **寫入這條路線** 寫回選中的那一條（同一層的點會自動對齊高度，原本路線裡的攻擊鍵照順序保留）。也可以先按 **載入目前路線** 把現有路線讀進來接著改。

### 第 5 步：開始掛機

按 **F10** 開始，再按一次 F10 停止。

開著「**掛機時邊打邊自學習**」（預設就是開的），程式會越掛越聰明：

- 沒有怪的層，只經過、不去巡。
- 怪重生要幾秒，就等幾秒，不會空等。
- 常常跳不上去的地方，會改走別的路。

## 四、職業小提醒（看你的職業要不要開）

每個職業的技能都不一樣，下面這些**預設都是關的**，符合你的職業再開。每一項在哪一頁，寫在表格裡。

| 你的職業如果… | 要做的設定 |
|---|---|
| **不能上跳**，只能爬繩、二段跳 | 「一鍵學圖」頁先 **框選繩子**（或在「座標路線」頁用 **框繩子加入路線** 直接框繩子換層、免學圖）；「移動設定」頁要填 **彈跳鍵** |
| 有**往背後移動**的位移技能（要面向反方向放） | 「攻擊」頁勾 **反向位移**，填技能鍵（試技能鍵通常會自動幫你填） |
| 主攻是兩招連段，**第一招要前方有怪才會衝過去** | 「攻擊」頁主攻鍵框**雙擊**後打字，寫成 `a,b`，再勾 **主攻第一段要確認位移才接下一段** |
| 要用**二段跳去追怪** | 「主動索敵」頁勾 **二段跳只用來接近怪物／找怪**（要開主動索敵） |

## 七、常見問題

**Q：按了 F10，角色完全不動？**
A：請確認是用「**以系統管理員身分執行**」開的。再看首頁有沒有顯示「已繫結」。

**Q：日誌一直說「小地圖上找不到人物黃點」？**
A：到「畫面識別」頁，重新按 **取色**，點自己角色的黃點；再按 **測試識別** 確認。
好友、公會成員或其他玩家站在你身上時，小地圖會把他們的點畫在你的黃點上面、整顆蓋住；程式會自己認出你在那顆點底下（測試識別會寫「黃點被別人的點整顆蓋住」）。只有兩個以上一樣的點疊在一起、又剛開主控臺時分不出是哪顆，走開一點再試就好。

**Q：好友、公會成員算不算「其他玩家」？**
A：算。小地圖上**紅點**是其他玩家、**青藍色圓點**是好友，公會成員也有自己的顏色，三種都會觸發自動回覆的「玩家訊息要小地圖有其他玩家」和來人提醒。不想算好友或公會，到「自動回覆」頁觸發條件，把「好友」或「公會」的勾拿掉。
自動回覆、來人提醒、**測試玩家點**都看「畫面識別」頁的小地圖範圍；換到小地圖比較寬的地圖，抓不到紅點時先按 **自動找小地圖**（或框選）把範圍設好。
人都是**圓點**；**直的橢圓點是 NPC**（綠色、洋紅色都有），不算人。程式只數圓點、外面有一圈深灰外框的，顏色相近的 NPC、地圖標記、地形不會被當成人。公會成員的顏色程式內建先當洋紅色，有公會成員在旁邊時，按「公會」那列的 **取色** 點一下他的圓點**中間**，再按 **測試玩家點** 看各抓到幾個。

**Q：怎麼讓它掛一陣子就回村休息、回來時找沒人的頻道？**
A：用「**定時回村**」頁：
1. 先到「死亡與回圖」頁設好回圖步驟（鍵鼠操作、座標操作或傳送石），按 **回圖測試** 確認回得去。
2. 「定時回村」頁勾 **啟用定時回村**，填掛機分鐘（例 `90-150`，每次隨機）、回村休息分鐘（例 `10-20`）和 **回家卷軸鍵**。暫停的時間不算在掛機時間裡。
3. 要找空頻：勾 **回圖後圖內有人就換頻**，按 **滑鼠座標小窗**，在遊戲裡打開換頻視窗、滑鼠移到要點的地方按 **F8** 一步一步記下來，最後按 **測試換頻** 試一次。
4. 回到戰鬥地圖會先看小地圖幾秒，有紅點、好友或公會的點就換頻，換到沒人才開打；換到上限每一頻都有人，就回村再休息一輪，連續三輪都有人會自動暫停並響鈴。
只看剛回圖那一下；之後才來的人交給自動回覆、來人提醒。回村途中不響鈴、不自動問話（村莊裡人很多），GM 訊息、測謊、補血補魔照常。只在座標模式作用。

**Q：怎麼知道滑鼠在遊戲畫面的哪裡、要點哪裡（點物品、換頻）？**
A：按 **滑鼠座標小窗**（定時回村、死亡與回圖的回圖操作、技能設定的間隔釋放與定點定時技能都有）。小窗會一直顯示滑鼠在遊戲畫面的座標，旁邊有放大鏡；在遊戲裡打開物品欄或換頻視窗，滑鼠移到要點的地方按 **F8**（「新增座標」熱鍵，可在「配置與快捷鍵」改）就記下，接到「加到」選的那一格，可以連記好幾點。記錯按 **復原上一個**；按 **預覽點擊位置** 會截一張遊戲畫面，標出那一格每一步點在哪裡。小窗開著時 F8 只記滑鼠位置、不加路線座標，關掉小窗就恢復。

**Q：血很低了卻不喝水？**
A：遊戲改版後血條位置可能變了。到「畫面識別」頁，把血條、魔條重新 **框選** 一次。

**Q：自動回覆送不出去？**
A：到「自動回覆」頁按 **框選輸入框…**，框住遊戲左下聊天視窗最底下那條白色輸入列，再按 **測試發話…** 試一次。

**Q：停止之後，好像有鍵一直卡住？**
A：按一下鍵盤上的 `Win` 鍵就會解除。

**Q：程式被防毒刪掉、打不開？**
A：看〈二、讓 Windows 不要擋程式〉的方法 1 和方法 3。

**Q：學圖排出來的路線走起來怪怪的？**
A：一鍵學圖頁重新按一次 **開始學圖**。學之前先確認繩子都框好了，角色站在比較平的地方再開始。

**Q：有新版要怎麼更新？**
A：1.4.0 起內建一鍵更新：有新版時主控臺上方會出現 **立即更新**，按下去就會自己下載、驗證、套用並重開，設定都不會動。從舊版升到 1.4.0 這一次還是要到下載頁手動下載（舊版還沒有這個功能），之後就能一鍵更新。一鍵更新下載不了、或檔案被防毒刪掉一部分時，到「授權與關於」頁按〔用下載好的 zip 更新／修復〕，選剛下載的 zip 就能套用或修復。

**Q：更新新版本後，設定要重設嗎？**
A：不用。第一次開新版時，會自動帶入上一版的配置、模板、錄製檔，還有自學習學到的資料。

**Q：可以縮小遊戲視窗嗎？**
A：不行。遊戲視窗可以被其他視窗蓋住，但**不能最小化**（最小化就看不到畫面了）。

## 八、其他

- **系統需求**：Windows 10／11 64 位元。不用另外安裝 Python 或其他程式，程式已經自帶。
- **放哪裡**：請把程式放在**純英文路徑**（例如 `D:\pikapang`），資料夾名也不要用中文——放在中文資料夾會讓防護功能失效。
- **更新（1.4.0 起內建一鍵更新）**：有新版時，主控臺上方會出現 **立即更新** 按鈕。按下後在背景下載、逐檔驗證更新包（這段時間主控臺照常可用），驗證完就關閉主控臺、套用新版並自動重新開啟（掛機中會先問你要不要現在停下來更新）。設定、模板、錄製檔、學圖資料都不會動，套用失敗會自動還原回原本的版本。
  - **從舊版升到 1.4.0 這一次仍要手動更新**（舊版還沒有一鍵更新），之後的新版才能一鍵更新。手動步驟＝下載新版 zip →**先關閉主控臺**→把裡面的 `pikapang` 資料夾解壓覆蓋到舊的那個上面；設定一樣自動保留，更新完會問要不要把舊版資料夾丟到資源回收筒。
  - 一鍵更新下載不了、或檔案被防毒刪掉一部分時：到「**授權與關於**」頁按〔**用下載好的 zip 更新／修復**〕，選剛下載的 zip，程式會驗證簽章後自己套用、重開；選同一版就是修復，設定不動。
